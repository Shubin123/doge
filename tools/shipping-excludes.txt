# Assets excluded from packaged builds (.love / .app / .exe / web).
#
# These files stay in the repo — most are the *source sheets* that
# tools/pack_atlas.py slices to build gfx/atlas/atla.dds.zlib, so they are
# needed to rebuild the atlas but never opened by the running game. The rest
# are stale build artifacts of that same pipeline.
#
# The list was derived empirically, not guessed: the game was run with every
# love.graphics.newImage / love.audio.newSource / love.filesystem.read call
# traced, and this is every file over 1 MB that was never touched. Anything
# under 1 MB is shipped regardless, so rarely-used lazy-loaded assets can't
# silently go missing to save a trivial amount of space.
#
# Paths are relative to src/. Re-check with tools/trace_assets.sh after
# adding art that loads on a code path the trace run didn't reach.
