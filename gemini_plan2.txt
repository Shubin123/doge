Instructions for SuperAI: Shader Code Reorganization Plan

Objective: Reorganize the 'src' directory to separate shader-related code from general game scripts for better organization and maintainability.

Plan:

1. Create a new subdirectory within the 'src' directory named 'shaders'.
   - Command (example): `mkdir src/shaders`

2. Move the existing shader file into the new 'shaders' directory.
   - Identify the main shader file, which is currently [`src/shader.lua`](src/shader.lua).
   - Move [`src/shader.lua`](src/shader.lua) to `src/shaders/shader.lua`.
   - Command (example): `mv src/shader.lua src/shaders/shader.lua` (Note: 'mv' might be 'move' on Windows, SuperAI should use appropriate command)

3. Update all references to the old shader file path.
   - Search the entire codebase within the 'src' directory for any `require` statements or direct references to `shader.lua` or `src/shader.lua`.
   - Update these references to the new path: `src/shaders/shader.lua`.
   - This step requires careful code modification across potentially multiple files.

Expected Outcome:
- The 'src' directory will contain a new 'shaders' subdirectory.
- [`src/shader.lua`](src/shader.lua) will no longer exist in the root of 'src'.
- A new file `src/shaders/shader.lua` will contain the shader code.
- The game should run without errors related to the shader file path, as all references will be updated.

This plan focuses specifically on the structural reorganization of shader code within the 'src' directory.
